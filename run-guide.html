How to organise, run, and test every file from Phase 1 to Phase 5

1 Complete Directory Structure

Create one root folder called printing-workflow/. This is also your GitHub repository root.

3 First-Time Setup (run once)

Terminal
# Create folder structure
mkdir -p printing-workflow/{dashboard,portal,reports/exports,backend/routes,backend/utils,automation,logs,.github/workflows}
cd printing-workflow

# Node.js dependencies (for backend)
cd backend && npm install && cd ..

# Python dependencies (for automation scripts)
pip install PyPDF2 pymupdf pandas openpyxl requests python-dotenv imapclient

# Create .env from template
cp backend/.env.example backend/.env
# Open backend/.env in any editor and fill in your keys

5 Testing Each Phase

Phases 1, 2, 4, 5 — HTML files (no server needed)

A

Double-click any HTML file

Works immediately in Chrome or Firefox. Best for a quick check.

B

Python local server (recommended for all pages together)

Terminal
cd printing-workflow
python3 -m http.server 8080
# Then open in browser:
http://localhost:8080/ ← Public website
http://localhost:8080/dashboard/ ← Staff dashboard
http://localhost:8080/portal/ ← Client portal
http://localhost:8080/reports/ ← MIS reports

Phase 3A — Node.js API

Terminal — open a NEW terminal window for this
cd printing-workflow/backend
node server.js

✓ PrintFlow API running on port 3000
Health: http://localhost:3000/health

# Test endpoints:
curl http://localhost:3000/health
curl http://localhost:3000/api/jobs
curl http://localhost:3000/api/dockets

Phase 3B — Python scripts

Terminal
# PDF Validator (give it any PDF)
python3 automation/pdf_validator.py /path/to/file.pdf

# Excel Processor (give it any xlsx or csv)
python3 automation/excel_processor.py /path/to/data.xlsx

# Generate MIS Excel Report
python3 automation/mis_report.py
Saved: reports/exports/PrintFlow_MIS_Report_May2025.xlsx

# Email Parser (needs .env filled in)
python3 automation/email_parser.py

6 Push to GitHub and Go Live

Terminal — run once from printing-workflow folder
cd printing-workflow
git init
git add .
git commit -m "PrintFlow Pro — all phases"
git remote add origin https://github.com/vitthal8/printing-workflow.git
git push -u origin main

Then: GitHub repo → Settings → Pages → Source: main branch / root → Save. Live in ~2 minutes.
